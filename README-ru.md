## Введение

В этом репозитории вы найдёте полностью восстановленный исходный код GTA VC.

Код протестирован и работает на Windows и Linux (amd64).\
Рендеринг осуществляется либо через реимплементацию [librw](https://github.com/aap/librw) (D3D9, OpenGL 2.1 и выше, OpenGL ES 2.0 и выше).\
Аудио работает через MSS (с использованием dll из оригинальной GTA) или OpenAL.

Мы пока не можем собрать версию для PS2 или Xbox. Если вам это интересно, свяжитесь с нами.

## Как попробовать?

- Для работы reVC требуются игровые ассеты, поэтому вы **должны** владеть [копией GTA Vice City](https://store.steampowered.com/app/12110/Grand_Theft_Auto_Vice_City/).
- Соберите reVC или скачайте последнюю сборку из [actions](https://github.com/AltronMaxX/reVC/actions) репозитория.
- Распакуйте скачанный zip-архив поверх вашей директории GTA VC и запустите reVC. Скачайте игровые файлы reVC из [этого](https://github.com/AltronMaxX/reVC-gamefiles/tree/main) репозитория.

## Улучшения

Мы внедрили ряд изменений и улучшений в оригинальную игру.
Их можно настроить в `core/config.h`.
Некоторые из них можно переключать во время выполнения, некоторые — нет.

* Пропуск телефонных звонков кнопкой входа/выхода из машины
* Автосохранения после миссий
* Исправлена работа игры на Linux с Wayland
* Исправлен текст миссии блюстителя закона для VCPD Cheetah
* Добавлен короткий путь из аэропорта в Sunshine Autos
* Увеличенная дальность прорисовки и лимит пешеходов/транспорта (WIP)
* Discord Rich Presence
* Исправлено множество мелких и крупных ошибок
* Пользовательские файлы (сохранения и настройки) хранятся в корневой папке GTA
* Настройки хранятся в файле reVC.ini вместо gta_vc.set
* Отладочное меню для различных действий и настроек (Ctrl-M для открытия)
* Отладочная камера (Ctrl-B для включения)

* Поддержка XInput-контроллеров (Windows)
* Без экранов загрузки между островами («использование памяти карты» в меню)
* Рендеринг
  * Поддержка широкоформатных экранов (корректно масштабированные HUD, меню и FOV)
  * PS2 MatFX (отражения на машинах)
  * PS2 alpha test (лучшее отображение прозрачности)
  * Xbox-рендеринг транспорта
  * Xbox-рендеринг карты освещения мира (требуется карта Xbox)
  * Xbox-подсветка пешеходов
  * Xbox-капли дождя на экране
  * Более настраиваемый цветовой фильтр
* Меню
  * Больше опций
  * Меню настройки контроллера
  * ...
* Возможность загружать DFF и TXD с других платформ (возможно с потерей производительности)

## Моддинг

Модификации ассетов (модели, текстуры, handling, скрипты и т.д.) по большей части должны работать так же, как и в оригинальной игре.

Моды, изменяющие код (dll/asi, CLEO, лимит-аджастеры), работать **не будут**.
Некоторые функции этих модов уже реализованы в reVC (большая часть SkyGFX, GInput, SilentPatch, Wide screen fix),
другие легко достигаются (увеличение лимитов, см. `config.h`),
третьи придётся переписывать и интегрировать напрямую в код.
Приносим извинения за неудобства.

## Сборка из исходников

При использовании premake вы можете указать переменную окружения GTA_VC_RE_DIR на корневую папку GTA Vice City, чтобы исполняемый файл перемещался туда через post-build скрипт.

Клонируйте репозиторий: `git clone --recursive -b miami https://github.com/AltronMaxX/reVC.git`. Затем перейдите в папку `cd reVC` внутри клонированного репозитория.

<details><summary>Linux Premake</summary>

Для Linux с использованием premake: [Building on Linux](https://github.com/AltronMaxX/reVC/wiki/Building-on-Linux)

</details>

<details><summary>Windows</summary>

Предполагается, что у вас установлена Visual Studio 2026:
- Запустите один из вариантов `premake-vs2026.cmd` в корневой папке.
- Откройте build/reVC.sln в Visual Studio и соберите решение.

Microsoft недавно прекратила распространение DX9 SDK. Вы можете скачать архивированную версию здесь: https://archive.org/details/dxsdk_jun10

**Если вы выбрали OpenAL на Windows**, необходимо прочитать [Running OpenAL build on Windows](https://github.com/AltronMaxX/reVC/wiki/Running-OpenAL-build-on-Windows).
</details>

> :information_source: premake имеет опцию `--lto`, если вы хотите собрать проект с Link Time Optimization.

> :information_source: В [config.h](https://github.com/AltronMaxX/reVC/tree/miami/src/core/config.h) есть различные настройки; возможно, вы захотите на них взглянуть.

> :information_source: reVC использует полностью самодельный движок рендеринга — замену RenderWare; [librw](https://github.com/aap/librw/). librw включён как подмодуль, но вы также можете использовать переменную окружения LIBRW для указания пути к вашей собственной librw.

При желании вы также можете использовать CodeWarrior 7 для компиляции reVC с помощью прилагаемого проекта codewarrior/reVC.mcp — для этого требуются оригинальные библиотеки RW34 и DX8 SDK. Однако такая сборка менее стабильна по сравнению со сборками MSVC и в основном предназначена для ознакомления.

## Участие в разработке

Если это не скелет/прослойка совместимости для Linux или кроссплатформенности, весь код в репозитории, не скрытый за препроцессорными условиями (например, FIX_BUGS), является **полностью** восстановленным кодом из оригинальных бинарников.

~~Мы **не** принимаем пользовательский код, если он не обёрнут в препроцессорные условия или не является скелетом/прослойкой совместимости для Linux или кроссплатформенности.~~

Мы принимаем PR только следующих типов:

- Новая возможность ~~которая существует хотя бы в одном релизе Vice City или поддерживаемом варианте платформы~~
- Исправления ошибок игры, UI или UX (если это исправление оригинального кода, оно должно быть под FIX_BUGS)
- Платформозависимый и/или неиспользуемый код, который ещё не был восстановлен
- Изменения, делающие восстановленный код более понятным/точным, т.е. «какой код породил бы эту ассемблерную инструкцию»
- Новый скелет/прослойка совместимости для кроссплатформенности или улучшения существующих
- Исправления перевода для языков, поддерживаемых оригинальной игрой
- Код, повышающий поддерживаемость

У нас есть [документ о стиле кода](https://github.com/AltronMaxX/reVC/blob/miami/CODING_STYLE-ru.md), который не очень строго соблюдается.
